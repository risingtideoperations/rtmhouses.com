# rtmhouses.com

Rising Tide Homes website. Static HTML/CSS/JS, hosted on GitHub Pages, custom domain `rtmhouses.com` (CNAME file).

- Listings load live in the browser from Tenant Turner's public feed (`app.tenantturner.com/listings-json/2342`) — nothing to hand-enter.
- "Apply" links resolve to each house's Rent Manager application via the Supabase view `site_unit_map`.
- Analytics and contact-form messages go to Supabase tables `site_events` / `site_messages`.
- Pages are generated by `build.py` (shared header/footer). Edit `build.py`, run `python3 build.py`, commit. `css/site.css` and `js/site.js` are edited directly.

Every push to `main` deploys automatically (`.github/workflows/pages.yml`).
